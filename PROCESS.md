# Описание процесса работы

1. Создан локальный репозиторий Git с названием `pep8-git-project`.
2. В первый коммит добавлены Python-файлы, конфигурации Black и Flake8,
   файл `.gitignore` и описание проекта.
3. Первый коммит переименован в `initial commit`.
4. Создана ветка `feature/add-multiplication`.
5. В ветку добавлена функция умножения и тест для неё.
6. В отдельном коммите временно создано нарушение PEP 8.
7. Нарушение исправлено: имена приведены к стилю `snake_case`, добавлены
   отступы, пробелы и строка документации.
8. Запущены Black, Flake8 и тесты.
9. Все проверки прошли успешно, рабочее дерево Git осталось чистым.

В проекте соблюдаются требования PEP 8: используются четыре пробела,
понятные имена, строки документации, правильное расположение импортов и
разделение функций пустыми строками.
